# ArcBridge — Base → Arc USDC Bridge

Static CCTP bridge frontend: moves USDC from Base to Arc. Your browser wallet signs; no backend, no secrets, no private keys ever leave the wallet.

## Local preview

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Enable via Settings → Pages, or push to `main` and this repo's Pages workflow deploys to z80.wtf/arcbridge.
